## Tujuan

Menyediakan satu tempat untuk menampilkan proyek, keahlian, dan cara menghubungi saya.

## Keputusan teknis

- **Astro** dipilih karena menghasilkan HTML statis: cepat dimuat dan ramah SEO.
- **Content Collections** dipakai untuk data proyek, sehingga menambah proyek baru
  cukup dengan menambah satu file Markdown.
- **Tailwind CSS v4** untuk styling dengan token warna kustom.

## Catatan

Situs ini sengaja dibuat tanpa JavaScript berat. Halaman tetap ringan dan bisa
dibuka cepat bahkan di koneksi lambat.
